# «Между строк» — личный архив Telegram

Статический сайт-архив переписки Дэна и Натальи по предоставленным файлам `result.json` и `messages.html`.

## Запуск

1. Распакуйте ZIP в отдельную папку.
2. Откройте `index.html` двойным щелчком в современном браузере (Chrome, Edge, Firefox).
3. Интернет не требуется для просмотра архива и поиска по тексту. Для перехода по внешним ссылкам интернет нужен.

Сайт не использует сервер, базы данных, API, фреймворки, шрифты и аналитику. Файлы `index.html`, `style.css`, `app.js`, `archive-data.js` должны находиться в одной папке.

## Содержание и возможности

- 595 записей экспорта: 528 сообщений и 67 событий/звонков за март–октябрь 2026 года.
- Поиск по тексту, авторам, вложениям и адресам ссылок.
- Навигация по 8 темам, датам и авторам; избранное (в памяти браузера).
- 97 уникальных веб-ссылок и 70 упоминаний файлов и фотографий.
- Ответы на сообщения, реакции, даты, исправления, просмотр контекста, экспорт отфильтрованных записей в TXT.
- Светлая и тёмная темы, мобильная версия, поддержка просмотра без интернета.

Тематические категории создаются по ключевым словам и могут иметь пересечения. Основная хронология включает **все** записи.

## Отсутствующие фото и видео

В предоставленных двух файлах были только пути к медиа (`photos/`, `video_files/` и т. д.), а не сами файлы. Карточки вложений сохраняют оригинальные названия и связь с сообщением. Позднее можно добавить исходные медиа, когда они станут доступны.

## Конфиденциальность — важно!

Это **личная переписка** (а не публичный канал). Из содержимого сайта удалены значения паролей и адреса электронной почты; Telegram user ID тоже не включены. Несмотря на это, другие сообщения могут содержать личные, деловые или конфиденциальные сведения.

**Не публикуйте сайт в открытом интернете без отдельной проверки содержимого и согласия участников переписки.** GitHub Pages по обычной ссылке является публично доступным сайтом. Метатег `noindex` не предотвращает доступ и не является защитой.

## Публикация на GitHub Pages

1. Создайте новый **публичный** репозиторий `mezhdu-strok` в своём аккаунте GitHub `dtebelev`.
2. Загрузите файлы из данного ZIP **в корень репозитория**, не помещая их в дополнительную папку.
3. Откройте **Settings → Pages**, выберите **Deploy from a branch**, ветку **main**, папку **/(root)**, нажмите **Save**.
4. Предполагаемый адрес после успешного развёртывания: `https://dtebelev.github.io/mezhdu-strok/`.

Файл `.nojekyll` предназначен для публикации неизменённых статических ресурсов. Никакого серверного кода нет.

**Важно:** это архив личной переписки. Пароли и адреса электронной почты скрыты, однако остальная личная и деловая информация в сообщениях остаётся. GitHub Pages общедоступен любому человеку со ссылкой, даже при наличии метатега `noindex`. Получите согласие всех участников на публикацию до размещения.

На момент упаковки публикация ещё не выполнена.

## Что можно менять

- Палитра и оформление: `style.css`.
- Заголовки, тексты, карточки и поиск: `app.js`.
- Название и метаданные: `index.html`.
- Обработанные сообщения Telegram: `archive-data.js`.

Архив оформлен как сохранение воспоминаний и исследовательская библиотека. Оригиналы `result.json` и `messages.html` в готовый ZIP **не включены**, чтобы избежать публикации паролей, которые могли присутствовать в исходных экспортах.
